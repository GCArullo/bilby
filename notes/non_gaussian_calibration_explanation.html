Non-Gaussian Runs With Calibration Uncertainty

This page explains what it means, in bilby and bilby_pipe, to run the non-Gaussian likelihoods with calibration-model=CubicSpline, calibration-correction-type=template, the same envelope files for H1 and L1, and calibration-marginalization=False.

1. Common calibrated waveform model

Let \( \theta \) denote the astrophysical source parameters, and let \( \lambda_I \) denote the calibration nuisance parameters for detector \( I \in \{H1, L1\} \). bilby applies calibration as a multiplicative correction to the detector waveform:

\[ h_I(f; \theta, \lambda_I) = C_I(f; \lambda_I)\, h_I^{(0)}(f; \theta), \]

where \( h_I^{(0)} \) is the usual detector response before calibration, and \( C_I \) is the calibration factor.

The residual used by all likelihoods is therefore

\[ r_I(f) = d_I(f) - C_I(f; \lambda_I)\, h_I^{(0)}(f; \theta). \]

So Gaussian, Student-\(t\), and hyperbolic runs all use the same calibrated signal model. What changes is only how the residual \( r_I(f) \) is scored.

2. What the cubic-spline calibration parameters are

With calibration-model=CubicSpline, bilby_pipe builds priors on spline-node amplitude and phase offsets for each detector:

\[ \lambda_I = \left\{ A^I_0, \dots, A^I_{N-1}, \phi^I_0, \dots, \phi^I_{N-1} \right\}. \]

These node values are interpolated in log-frequency to obtain smooth functions \( \delta A_I(f) \) and \( \delta \phi_I(f) \). The implemented calibration factor is

\[ C_I(f; \lambda_I) = \bigl(1 + \delta A_I(f)\bigr) \frac{2 + i\,\delta \phi_I(f)}{2 - i\,\delta \phi_I(f)}. \]

The envelope files do not force H1 and L1 to share the same sampled nuisance parameters. They only mean that the two detectors use the same prior construction scheme, with separate detector-labeled parameters such as \(A^{H1}_k\) and \(A^{L1}_k\).

3. Meaning of calibration-correction-type=template

bilby distinguishes two conventions for calibration corrections. In the template convention,

\[ d_I(f) = C_I(f)\, h_I^{(0)}(f; \theta) + n_I(f), \]

so the calibration factor multiplies the waveform template directly.

In the opposite data convention one would write

\[ h_I(f) = \eta_I(f)\, d_I(f), \qquad \eta_I(f) = C_I(f)^{-1}. \]

Therefore calibration-correction-type=template means the calibration envelope is interpreted as a template-to-data correction, not its inverse.

4. Meaning of calibration-marginalization=False

This is the key point. These runs are not marginalizing over a pre-drawn bank of response curves. Instead, the sampler explicitly samples the spline calibration nuisance parameters together with the astrophysical and noise-model parameters.

The target posterior is

\[ p(\theta, \lambda_{H1}, \lambda_{L1}, \psi \mid d) \propto \mathcal{L}\bigl(d \mid \theta, \lambda_{H1}, \lambda_{L1}, \psi\bigr)\, p(\theta)\, p(\lambda_{H1})\, p(\lambda_{L1})\, p(\psi), \]

where \( \psi \) denotes the noise parameters. For example:

  • \( \psi = \nu \) for the Student-\(t\) likelihood.
  • \( \psi = (\alpha, \delta) \) for the hyperbolic likelihood.

Source-only posteriors are then obtained by integrating out the calibration parameters from the samples.

5. What calibration marginalization would have been instead

If calibration-marginalization=True, bilby would use a different calculation: draw or load a finite set of calibration response curves \( \lambda^{(j)} \), and replace the likelihood by

\[ \mathcal{L}_{\mathrm{cal\,marg}}(d \mid \theta, \psi) = \int d\lambda\; \mathcal{L}(d \mid \theta, \lambda, \psi)\, p(\lambda) \approx \frac{1}{N_{\mathrm{curves}}} \sum_{j=1}^{N_{\mathrm{curves}}} \mathcal{L}\bigl(d \mid \theta, \lambda^{(j)}, \psi\bigr). \]

That is a discrete average over response curves. Your runs are explicitly not doing this.

6. What changes in the non-Gaussian runs

The non-Gaussian likelihoods inherit the same calibrated detector response machinery as the Gaussian run. The only change is the functional form of the likelihood for the residual \(r_I(f)\).

Schematic examples are:

\[ \log \mathcal{L}_{\mathrm{Gauss}} \sim -\frac{1}{2} \sum_{I,f} \frac{|r_I(f)|^2}{\sigma_I^2(f)}, \] \[ \log \mathcal{L}_{\mathrm{Student}\mbox{-}t} \sim -\frac{1}{2} \sum_{I,f} \bigl(\nu + 2\bigr) \log\!\left(1 + \frac{|r_I(f)|^2}{\nu\,\sigma_I^2(f)}\right), \]

with a different heavy-tailed form again for the hyperbolic case.

So “non-Gaussian run with calibration” means: use a heavy-tailed likelihood for the same calibrated residual, while still sampling the spline calibration nuisance parameters from priors derived from the envelope files.
