## Model and preserved settings

The `--sg-only` option uses `bilby.gw.source.sine_gaussians`: CBC strain is
exactly zero and no CBC waveform is evaluated. CBC masses, spins, distance,
inclination and phase are absent from the priors. Source aggregation is shared
with the CBC+SG implementation.

Each configuration was derived from the corresponding completed/generated
CBC+SG config. Data channels, PSDs, trigger time, duration, sample rate,
detector reference frame/time, SG priors (including amplitude ordering),
calibration priors, and sampler settings were retained. In particular,
`time_offset` remains uniform on [-0.15, +0.15] s and the reference epoch
remains sampled over the original 0.2 s window.

Calibration remains active: 40 sampled amplitude/phase coefficients in each
H1+L1 run and 20 in each single-detector run, plus the fixed frequency nodes.
The PESummary `recalib*` filter never disabled calibration inference.

CBC approximant variants are redundant without CBC. Common/independent CBC–SG
sky variants use one canonical coherent SG-only family, with the common-sky
reference-time convention and no unphysical second CBC sky. Single-detector
coherent SGs are not duplicated by detector-local SGs: antenna projection
gives them different induced amplitude priors.

Automatic CBC-specific summary pages and waveform plots are disabled.
Posterior generation retains sky conversion, per-detector likelihoods,
total/SG SNRs, and exactly zero CBC component SNRs. Generic SG-only summary
pages can be generated from the completed results.
