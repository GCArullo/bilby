# GW190521_030229 LVK NRSur7dq4 Reproduction

```
BASE_DIR="$(git rev-parse --show-toplevel)"
UTILS="$BASE_DIR/examples/gw_examples/data_examples/Cluster_runs_and_utils"
REAL="$UTILS/submit_runs_real_data.py"
SPECIAL_CONFIGS="$UTILS/Special_events_configs"
```

The `GW190521_030229_LVK_NRSur7dq4` profile is a Bilby translation of the
NRSur7dq4 LALInference configuration released with LIGO-P2000158-v4. It retains
the released 8 s duration, 1024 Hz sampling rate, 11 Hz analysis and reference
frequencies, three-detector network, NRSur7dq4 signal model, mass bounds, PSDs,
and calibration envelopes.

The source configuration extracted from the release is:

```
$SPECIAL_CONFIGS/source_configs/GW190521_030229_LVK_NRSur7dq4.ini
```

The original analysis used LALInferenceNest. This workflow uses Dynesty because
`submit_runs_real_data.py` compares Gaussian and heavy-tailed Bilby likelihoods;
the signal, data-conditioning, and prior settings are the translated parts.

## Prepare released products

Download the 158.9 MB LVK archive, verify its published MD5 checksum, and
extract the NRSur7dq4 PSDs and calibration envelopes:

```
python "$SPECIAL_CONFIGS/prepare_gw190521_030229_lvk_nrsur7dq4.py"
```

The ignored local products are written below:

```
$SPECIAL_CONFIGS/data/GW190521_030229_LVK_NRSur7dq4
```

The template transfers the surrogate data file from:

```
/home/pe.o4/GWTC4-fogg/NRSur7dq4_v1.0.h5
```

Confirm that this shared path is readable from the submit host.

## Gaussian reproduction

Generate the configuration without submitting:

```
python "$REAL" \
  --event GW190521_030229_LVK_NRSur7dq4 \
  --likelihood gaussian \
  --dry-run
```

Remove `--dry-run` to submit. Results are written below:

```
$HOME/public_html/GWTC_parametric_noise/Runs/GW190521_030229
```

## Student-t likelihood

The same profile accepts `--likelihood student`, retaining the translated LVK
signal analysis while changing the noise likelihood:

```
python "$REAL" \
  --event GW190521_030229_LVK_NRSur7dq4 \
  --likelihood student \
  --num-frequency-bands 1 \
  --no-add-gaussian \
  --dry-run
```
