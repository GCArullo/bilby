# GW241127 SEOB and pSEOB runs

These profiles reproduce the configuration embedded in
`pSEOB/metafiles/pSEOB_GW241127_061008_Prod0.h5` from
[Zenodo record 21454847](https://zenodo.org/records/21454847). These profiles
extend the released H1/V1 pSEOB setup with L1, using the L1 channel, 30-Hz
cutoff, PSD, and calibration settings from the GWTC-5 parameter-estimation
configuration.

Set up the released inputs under:

```text
$HOME/LVK_posteriors/GW241127_061008/
├── calibration/
│   ├── H1.txt
│   ├── L1.txt
│   └── V1.txt
├── data/
│   ├── H-H1_HOFT_AR01-1416720384-4096.gwf
│   ├── L-L1_HOFT_AR01-1416720384-4096.gwf
│   └── V-HoftAR1U02-1416722000-2000.gwf
└── psd/
    ├── glitch_median_PSD_forLI_H1.dat
    ├── glitch_median_PSD_forLI_L1.dat
    └── glitch_median_PSD_forLI_V1.dat
```

The input strain, PSD, and calibration products are not included as standalone
files in the plotting release. The paths and filenames above are those stored
in its embedded analysis configuration. The released distance-marginalization
lookup table is also absent, so these templates leave its path unset and Bilby
builds a new table. The launcher applies its standard 16-CPU, 24-GB resource
request to generated jobs.

```bash
BASE_DIR="$(git rev-parse --show-toplevel)"
REAL="$BASE_DIR/examples/gw_examples/data_examples/Cluster_runs_and_utils/submit_runs_real_data.py"
```

Run the ordinary SEOBNRv5PHM baseline:

```bash
python "$REAL" --event GW241127_SEOB --likelihood gaussian --minimum-frequency 20
```

Run the released pSEOBNRv5PHM parameterization, which varies
`domega220` and `dtau220`:

```bash
python "$REAL" --event GW241127_pSEOB --likelihood gaussian --minimum-frequency 20
```

Use `--minimum-frequency 30` for the corresponding 30-Hz analysis. The option
sets every detector cutoff and adds `_fmin20` or `_fmin30` to labels,
filenames, and run directories. The waveform-start frequency remains 13.33 Hz.

For a Student-t comparison with one through four frequency bands and its
Gaussian companion, replace `--likelihood gaussian` with:

```bash
--likelihood student --range --num-frequency-bands 4
```

Outputs are placed in separate `SEOB` and `pSEOB` subdirectories under
`$HOME/public_html/GWTC_parametric_noise/Runs/GW241127_061008`.
