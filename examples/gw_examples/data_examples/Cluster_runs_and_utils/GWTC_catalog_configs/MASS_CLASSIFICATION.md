# GWTC mass classification

Events are classified using the published LVK median source-frame total
mass \(M=m_1+m_2\) from the catalog source-property tables. The published
mixed-waveform result is used when available; a published single-waveform
result is used otherwise. Values below are transcribed from the tables, not
recomputed from posterior samples.

- **High mass:** \(M_\mathrm{median}>50\,M_\odot\)
- **Low mass:** \(M_\mathrm{median}\leq50\,M_\odot\)

The equality case is assigned to low mass so that the two classes are
exhaustive.

- [GWTC-4 LVK catalog paper](https://arxiv.org/abs/2508.18082)
- [GWTC-5 LVK catalog paper](https://dcc.ligo.org/P2600152/public)
